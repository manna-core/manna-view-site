Manna VideoPlayer · Local utility

A little more video. A little less page.

An app-style window for watching a YouTube link with less surrounding interface.

Ask about this project →

The idea

The local launcher opens an embedded player when the video allows it. When embedding is blocked, it offers a focused watch-page fallback.

What it explores

  • Paste-and-open launch
  • Standard player controls and fullscreen
  • An explicit fallback for blocked embeds

Where it stands

Local utility

Requires Chrome locally. Uploader and platform restrictions still apply; the watch-page fallback is not identical to the embedded player.
