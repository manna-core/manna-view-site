Manna Audio Link · Released · Windows

Two computers. One set of headphones.

Send a laptop’s system audio across your local network to the computer you already listen to.

Download Audio Link ↗

The idea

A sender runs on one Windows computer and a receiver plays through the other. The Sound Sync tray controls the receiver; the Send Audio launcher handles the source.

What it explores

  • Separate sender and receiver installers
  • Local-network audio with saved configuration
  • Visible connection and audio diagnostics

Where it stands

Released · Windows

Public release v0.1.3. The original two-computer stream was tested in use; the latest installer path still needs broader two-machine testing. Intended for a trusted local network.
