Manna Digest · Local utility prototype

Keep the useful parts of what you watch.

A local pipeline for turning video and audio into structured, timestamped notes.

Ask about this project →

The idea

Digest works from available captions or local media, then organizes transcripts into reviewable notes. Saved transcript artifacts can be processed again without starting from scratch.

What it explores

  • Caption and local-media intake
  • Local transcription and digest-provider options
  • Timestamped notes and video-still extraction

Where it stands

Local utility prototype

The command-line pipeline has been exercised on local media. A finished user interface, automatic memory updates, and reliable transcript-to-frame alignment are not part of the current release.
