Jericho Upgrade Kit · Public repository

A practical kit for clearer project work.

Reusable planning, continuity and review materials for an existing software project.

Explore the public kit ↗

The idea

The public kit packages project state, next steps, prompts, examples, and cautious upgrade workflows. It helps a builder keep the work understandable between sessions.

What it explores

  • Project-state and next-step templates
  • Review prompts and examples
  • Small, reversible upgrade workflows

Where it stands

Public repository

The public kit is separate from any private customer or production system. Read its repository instructions before use.
